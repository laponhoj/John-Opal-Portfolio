# John Opal — Sales & Client Relationships Portfolio

A responsive, static portfolio website tailored toward a Sales Development Representative / Market Development Representative application.

## What's included
- `index.html` — portfolio content and semantic page structure
- `styles.css` — responsive visual styling
- No build tools or JavaScript dependencies required

## Before publishing
1. Open `index.html`.
2. Find `YOUR_EMAIL_HERE` and replace it with your actual email address.
3. Find `YOUR_LINKEDIN_URL_HERE` and replace it with your actual LinkedIn profile URL.
4. Check every metric and statement against your résumé and experience before sharing.
5. Consider adding a professional headshot if you'd like, but it is optional.

## Publish with GitHub Pages
1. Sign in to GitHub and create a **public** repository named `john-opal-portfolio` (or another name you prefer).
2. Upload `index.html`, `styles.css`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under the build/deployment source, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish. The site URL is usually `https://YOUR-GITHUB-USERNAME.github.io/john-opal-portfolio/`.

GitHub's interface can change, so follow the current prompts shown in repository Settings → Pages.

## Accuracy notes
This portfolio reframes résumé experience into concise case studies. It does not claim DocuSign experience, quota attainment beyond the stated $6,000/day holiday-season quota, prospecting metrics, conversion rates, or other results not provided in the résumé. Edit anything that doesn't accurately reflect your role.
